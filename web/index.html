          Qué hace este sistema y cuánto fiarse

          Qué hace

          Cada transacción pasa por dos señales. Las reglas fijas comprueban el monto y, en los datos sintéticos, si el país es distinto del habitual. El modelo Isolation Forest da una puntuación de anomalía: cuanto mayor, más rara es la transacción frente a las que vio al entrenar. n8n combina las dos señales en un nivel y deja el caso para revisión humana.

          Cuánto fiarse

          Cargando el estado del modelo…

          Una puntuación alta prioriza la revisión; no prueba el fraude. Los contadores de esta página solo describen el lote mostrado. Las métricas con intervalos de confianza están en comparativa.md, en la carpeta de evidencia.

          Qué no hace

          No bloquea operaciones ni se conecta a ningún banco. El conjunto original no trae ubicación ni moneda: la regla de ubicación solo se prueba con datos sintéticos, y el umbral de monto se aplica a la cifra tal cual.

          Prototipo académico de detección híbrida: reglas deterministas, Isolation Forest y n8n.
